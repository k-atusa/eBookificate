계획

책 스캔, 이미지 변환을 하는 앱을 만들고자 한다.

1. 앱에 들어오면 메뉴가 보인다.
- Convert: 이걸 누르면 새 액티비티에서 사용자는 이미지 선택, 모드 선택, 변환을 할 수 있다.
    - 이미지를 선택하면 몇 개 선택했는지 뜬다.
    - 모드는 none, jpg, png, webp, webp(lossless), webp(half) 가 있다. none은 형식 변화 안함. webp-half는 가로세로 해상도를 반으로 줄인 webp.
    - 변환 시 항상 모든 메타데이터를 지우고 딱 이미지 데이터만 남긴다.
    - 결과는 다운로드 폴더에 eBookificate 폴더에 저장된다. 타겟 파일명을 그대로 사용한다.
    - 변환 누르면 몇 개 변환되었는지 뜨다가 완료가 뜬다.
- Storage:
    - 스캔 저장소 공간은 5개를 보여주며, 각각은 A~E 의 하위 폴더에 대응된다.
    - 기본 이름은 "Scan 1" ~ "Scan 5" 이나, 바꿀 수 있는 버튼이 있다.
    - 이걸 누르면 저장소 공간으로 간다.

2. 저장소 공간
- 저장소의 스캔한 이미지가 썸네일과 이름으로 보인다.
- 한 번에 30개까지 표시하고 하단에 페이지가 표시된다. 좌우 버튼으로 넘길 수 있다.
- 이미지를 꾹 누르면 삭제 메뉴가 뜬다.
- 상단엔 메뉴가 있다. 메뉴는 실행 전 항상 확인을 받아야 한다.
- 변환: jpg, png, webp, webp(half) 모드 지원.
- 추가: 새 사진을 찍어 추가한다. 하나 찍으면 끝이 아니고 뒤로가기 할때까지 계속 이미지 찍는 화면이다.
- 내보내기: 모든 파일을 zip으로 묶어 eBookificate 폴더에 내보낸다.
- 초기화: 저장소를 초기화한다.
- 이미지 이름 저장 형식은 A00000.jpg 형태다. 내보내기 시 zip 파일 이름은 "A.zip" 형태다.
- 자동으로 숫자를 채운다. 이때 큰 것을 기준으로 한다. (0, 1, 3이 있다면 4로 저장)

3. 라이브러리
- 공통적으로 쓰이는 기능은 core.java에 합치면 편할 것 같다.
